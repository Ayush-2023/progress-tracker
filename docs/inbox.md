# Inbox

Raw dump. Newest on top. Write the idea first; add relations later at the weekly sort.

## Entry format

```
### I-000 · Short title
- Date: YYYY-MM-DD
- Status: open
- Specializes: [[I-000]]   narrower case of a broader idea
- Generalizes: [[I-000]]   broader version of a narrower idea
- Related: [[I-000]]       connected, neither contains the other
- Conflicts: [[I-000]]     can't both be true
- Motto: 1 or 2
```
