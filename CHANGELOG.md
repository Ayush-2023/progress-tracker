# Changelog

Newest on top. Each release matches a git tag and links the ideas it shipped.

Versions stay on `0.x` while this is a proof of concept:

- Middle number (`v0.2.0`): a new set of ideas has shipped.
- Last number (`v0.2.1`): fixes only.
- `v1.0.0`: relied on day to day.

## Unreleased

- Added: Finishing, reopening and archiving goals.
- Added: Maintenance goals repeat on a schedule, with check-ins and streaks.
- Added: Achievements, attached to any goal item or left unattached.
- Added: Reminders as a list, with no notifications.
- Added: Open blockers shown as a visible flag, with no auto-pausing.
- Added: Saving in the browser, with JSON export and import.
- Added: Light, Dark and Programmer themes.
- Added: Installs to a phone's home screen and works offline.
- Fixed: The phone's status bar and bottom bar area now follow the app's theme instead of staying white.
