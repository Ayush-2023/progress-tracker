# Progress Tracker

A personal system for tracking goals, achievements and reminders.

Status: proof of concept (v0). Plain HTML, CSS and JavaScript, with no build step or dependencies.

## Run it

Open `app/index.html` in a browser. Your data is saved only in that browser, so use the same one each time and export a backup regularly.

## Live site

https://ayush-2023.github.io/progress-tracker/

Every push to `main` publishes the `app/` folder there through GitHub Actions (`.github/workflows/pages.yml`).

## Install on a phone

Open the live site in Safari on iPhone and choose Share → Add to Home Screen (on Android, Chrome offers Install app). It then opens full screen and works offline. Data on the phone is separate from other devices, so use Export and Import to move it.
